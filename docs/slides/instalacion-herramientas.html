Primeros pasos

Abre la terminal

No es hackear: es darle instrucciones al computador, una por una.

  1. Busca PowerShell en el menú de inicio y ábrela.
  2. Escribe cd Desktop y presiona Enter para ir al escritorio.
  3. Escribe mkdir prework para crear una carpeta nueva.
PS ~> cd Desktop PS ~\Desktop> mkdir prework PS ~\Desktop> ls prework
Opcional · dos minutos

Hazla tuya

Una terminal con buen color da más ganas de abrirla.

  1. Instala Windows Terminal desde la Microsoft Store (en Windows 11 ya viene).
  2. Ábrela y entra a Configuración, en el perfil de PowerShell.
  3. En Apariencia, elige un esquema de color, por ejemplo One Half Dark o Solarized Dark.
  4. Si la letra se ve chica, sube el tamaño de fuente ahí mismo.
Instalación

Instala Python

  1. Entra a python.org/downloads.
  2. Descarga la versión para Windows: el sitio la detecta sola.
  3. Abre el instalador y marca Add Python to PATH antes de instalar.
  4. Sigue el asistente hasta el final y ciérralo.
Verifica

¿Quedó instalado?

Abre la terminal y escribe esto:

PS> python --version Python 3.12.4

Si el número de versión es otro pero empieza por 3, está bien.

Déjalo listo

Permite que PowerShell ejecute scripts

Windows los bloquea por defecto. Más adelante necesitarás uno para activar un entorno virtual de Python: mejor resolverlo ahora.

PS> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Si te pregunta, confirma con «S».

El programa, no la cuenta

Instala Git

  1. Entra a git-scm.com/downloads.
  2. Descarga el instalador para Windows.
  3. Instala dejando todas las opciones por defecto.
Configura y verifica

Dile quién eres y comprueba que quedó

PS> git config --global user.name "Tu Nombre" PS> git config --global user.email "tu@email.com" PS> git --version git version 2.45.0

Usa el mismo correo con el que crearás tu cuenta de GitHub.

Tu cuenta

Crea tu cuenta de GitHub

  1. Entra a github.com.
  2. Haz clic en Sign up.
  3. Elige un nombre de usuario, tu correo y una contraseña.
  4. Confirma la cuenta desde el correo que te llega.

Si ya tienes cuenta, pasa a la siguiente slide.

Conecta Git con tu cuenta

Así no te pide usuario y contraseña cada vez

  1. Instala GitHub CLI desde cli.github.com.
  2. En la terminal escribe gh auth login.
  3. Elige GitHub.com, luego HTTPS y Login with a web browser.
  4. Copia el código que te muestra, pégalo en el navegador que se abre y confirma.
PS> gh auth login ? Where do you use GitHub? GitHub.com ? Preferred protocol for Git? HTTPS ? Authenticate Git with your GitHub credentials? Yes ? How would you like to authenticate? > Login with a web browser
Confirma la conexión

De vuelta en la terminal

PS> gh auth setup-git PS> gh auth status Logged in to github.com as tu-usuario

Ya está todo conectado. Lo que falta, tu primer commit, lo hacemos en el encuentro.

6 · Power BI

Instala Power BI Desktop

Es la herramienta con la que construirás tu tablero. Es gratis.

  1. Abre la Microsoft Store y busca Power BI Desktop.
  2. Haz clic en Obtener o Instalar y espera a que termine.
  3. Ábrelo. Si te pide iniciar sesión, puedes cerrar esa ventana: para practicar no la necesitas.

Alternativa: descárgalo desde powerbi.microsoft.com/desktop.

6 · Power BI · verifica

¿Funciona? Carga un archivo

  1. Crea en tu escritorio un archivo de texto con tres líneas y guárdalo como prueba.csv.
  2. En Power BI Desktop entra a Inicio → Obtener datos → Texto o CSV.
  3. Elige prueba.csv y haz clic en Cargar.
  4. Si la tabla aparece en el panel Datos, ya está listo.

Publicar y compartir reportes pide una cuenta; eso lo vemos más adelante.

Antes de llegar al encuentro

Si todo esto funciona, estás lista o listo

  • La terminal abre sin error
  • python --version responde, y PowerShell ejecuta scripts
  • VS Code abre y puede crear un archivo
  • git --version responde
  • Tienes tu cuenta de GitHub y gh auth status muestra tu usuario
  • Power BI Desktop abre y carga un archivo CSV

Docker y Airflow

Los usa el nivel intermedio. Si eres de nivel básico y te da curiosidad, puedes instalarlos, pero no es obligatorio y no los necesitas para el curso.

Solo nivel intermedio · opcional si eres básico

Instala Docker Desktop

  1. Entra a docker.com/products/docker-desktop y descarga Docker Desktop para Windows.
  2. Abre el instalador y deja marcada la opción de WSL 2.
    Es lo que permite a Docker correr en Windows.
  3. Reinicia el computador si te lo pide.
  4. Abre Docker Desktop y acepta los términos.
    Déjalo abierto: Docker trabaja mientras la aplicación está corriendo.
Solo nivel intermedio · opcional si eres básico

¿Quedó funcionando?

PS> docker --version Docker version 27.0.3 PS> docker run hello-world Hello from Docker!

Para Airflow, en Docker Desktop entra a Settings → Resources y asigna al menos 4 GB de memoria (mejor 8 GB).

Solo nivel intermedio · opcional si eres básico

Airflow: descarga su configuración

Lo corremos con Docker, así que solo necesitas un archivo y cuatro carpetas.

PS> mkdir airflow PS> cd airflow PS> curl.exe -LfO 'https://airflow.apache.org/docs/apache-airflow/3.4.0/docker-compose.yaml' PS> mkdir dags, logs, plugins, config

En PowerShell, curl.exe es el comando; curl a secas es otra cosa.

Solo nivel intermedio · opcional si eres básico

Airflow: inicialízalo y ábrelo

PS> docker compose up airflow-init PS> docker compose up
  1. Espera a que el primer comando termine con exited with code 0.
  2. Con el segundo corriendo, abre http://localhost:8080 en el navegador.
  3. Entra con usuario airflow y contraseña airflow.

Si te avisa de AIRFLOW_UID, es normal. Para silenciarlo, crea un archivo .env con AIRFLOW_UID=50000.

Solo nivel intermedio · opcional si eres básico

Y cuando termines, apágalo

Airflow consume bastante memoria. En la terminal donde está corriendo, presiona Ctrl + C, y después:

PS> docker compose down

Para volver a usarlo, repite docker compose up dentro de la carpeta airflow.

¿Algo no instaló bien?

Esto no es un examen.

Es para que el encuentro arranque directo. Si algo falla, escríbele a tu profesor antes, con una captura del error. No esperes al último minuto.
