Una trampa muy común

¿Cuántas personas leyeron «Dune»?

prestamo_id socio_id libro fecha 101 7 Dune 2026-03-02 102 9 Emma 2026-03-05 103 7 Dune 2026-03-12
  • Hay dos filas de «Dune»…
  • …pero solo una persona: la 7 lo pidió dos veces.
  • Una fila es un préstamo, no una persona. Por eso la ficha pide la unidad de cada fila.

Fuentes

Una o dos fuentes que puedas manejar

  • Una fuente principal que tengas hoyUn archivo, una tabla de BigQuery o un conjunto de datos abiertos
  • Si solo tienes una tabla, mira si una segunda fuente descriptiva ayudaPor ejemplo, un catálogo de libros, de productos o de sedes
  • Si no hay una, crea un catálogo sintético y diloSirve para practicar la unión; no se presenta como fuente real
Datos de personas

Antes de pedir un archivo, busca una alternativa

  • Si tu idea usa datos de clientes, estudiantes o pacientes, busca primero una versión pública o sintética.
  • Una idea puede ser buena aunque cambie su fuente.
  • Tu proyecto no debe depender de conseguir permisos durante la clase.

De la ficha a los datos

La unidad de fila se comprueba con SQL

En Platzi estás viendo los fundamentos. Aquí los usamos para una sola cosa: entender qué hay en una tabla.

SELECT prestamo_id, socio_id, libro, fecha FROM prestamos LIMIT 5;

Primero se mira, después se calcula.

Una buena práctica desde el comienzo

Nombra las columnas que necesitas

EvitaSELECT * FROM prestamos
PrefiereEscribir las columnas que necesitas y limitar las filas mientras exploras.

Se lee mejor, cuesta menos en BigQuery y deja claro qué estás mirando.

Filas frente a personas

Cuenta filas, y cuenta personas distintas

SELECT COUNT(*) AS prestamos, COUNT(DISTINCT socio_id) AS socios FROM prestamos; prestamos | socios 3 | 2

Si los dos números son distintos, una fila no es una persona. Anótalo en la ficha.

Un indicador por un corte

GROUP BY resume por una dimensión

SELECT libro, COUNT(*) AS prestamos FROM prestamos GROUP BY libro ORDER BY prestamos DESC; libro | prestamos Dune | 2 Emma | 1

El indicador es «préstamos»; el corte es «libro». Así sale cada fila de tu ficha.

Práctica guiada · 15 minutos

Conoce tu tabla con tres consultas

  1. Mira cinco filas con LIMIT 5 y nombra las columnas.
  2. Cuenta las filas y cuenta las entidades distintas con COUNT y DISTINCT.
  3. Escribe en tu ficha: «cada fila representa…».

Usa BigQuery con un dataset público o tu muestra.

Apache Airflow

Es quien ordena, programa y vigila las tareas

Cuatro palabras de Airflow

Lo mínimo para entenderlo

1DAGEl flujo completo: tareas y el orden entre ellas
2TareaUn paso: traer, limpiar, calcular
3ProgramaciónCuándo corre: cada hora, cada día, cada lunes
4RegistroLo que pasó en cada ejecución, bueno o malo

Es un DAG porque las tareas van en un solo sentido y no se cierran en círculo.

  3. Actívalo y pulsa Trigger para ejecutarlo una vez.
  4. Abre la vista del DAG y el registro de una tarea.
