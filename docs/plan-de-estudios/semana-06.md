# Semana 6 — Gestión de proyectos y arranque del integrador

Módulo del pensum: 6. Gestión de proyectos de ciencia de datos (Scrum, pipelines de datos, colaboración en equipos) y arranque del 8. Proyecto integrador.
Trabajo: **T5** Pipeline y backlog (entrega al final de la S12).
Dimensiones: Producción, Datos y Dirección de IA. Hilo de Habilidades para el empleo.
Elasticidad: **elástica**. Si el curso va atrasado, el pipeline se acorta y el tiempo se reserva para el integrador.

---

## S11 — Scrum, equipos y arranque del integrador (presencial, sesión A)

**Objetivo:** formar equipos, repartir roles y dejar listo el backlog y el sprint 1 del proyecto integrador.

| Min | Dinámica | Detalle |
|---|---|---|
| 0–15 | Retro y votación | Cómo vas con el curso. Votación en vivo: «¿qué rol te cuesta más asumir?» |
| 15–45 | Concepto | Scrum aplicado a ciencia de datos: roles, backlog, sprints, definición de terminado |
| 45–55 | Pausa | |
| 55–95 | Formación de equipos | Equipos equilibrados con el radar de entrada y los roles que cada uno prefiere. Cada equipo elige un problema y un dataset |
| 95–105 | Pausa | |
| 105–165 | Planificación del sprint 1 | Cada equipo escribe su backlog en el tablero, estima tareas y define el objetivo del sprint |
| 165–180 | Cierre | Cada equipo presenta su objetivo en una frase |

**Materiales:** tablero en el repo o en el espacio del equipo, plantilla de backlog, lista de roles (analista de datos, ingeniero de pipelines, modelador, narrador).

## S12 — Pipelines reproducibles (virtual, sesión B)

**Objetivo:** convertir el análisis en un flujo reproducible que otro equipo pueda ejecutar.

| Min | Dinámica | Detalle |
|---|---|---|
| 0–10 | Preguntas pendientes | |
| 10–50 | Concepto | Pipelines de datos: extraer, transformar, cargar; scripts frente a notebooks; configuración y semillas |
| 50–60 | Pausa | |
| 60–120 | Trabajo del PR | Los equipos construyen su pipeline en salas, con el sprint 1 como guía |
| 120–130 | Pausa | |
| 130–160 | Revisión al azar | 3 min por equipo: «¿qué entra, qué sale y cómo se reproduce?» |
| 160–180 | Retrospectiva del sprint 1 | Qué salió bien, qué no, qué cambia en el sprint 2 |

## Rúbrica de T5 — Pipeline y backlog

| Criterio | Dimensión | Nivel 5 se ve así |
|---|---|---|
| Pipeline reproducible | Producción | Otro equipo lo ejecuta sin ayuda y obtiene el mismo resultado |
| Calidad de los datos que produce | Datos | Se validan esquema y valores, con mensajes claros cuando algo falla |
| Backlog y avance | Producción | Tareas pequeñas, estimadas, con responsable y evidencia de avance |
| Declaración de IA | Dirección de IA | Bitácora del equipo, con la verificación del código generado |

## Habilidades para el empleo

Roles de equipo, comunicación en el equipo, retrospectivas y retroalimentación entre pares.
